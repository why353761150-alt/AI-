# 📚 AI辅助阅读助手 (AI Reading Coach)

一个运行在 [WorkBuddy](https://workbuddy.ai) 上的智能阅读 Skill，将书籍分为六种类型，为每种类型匹配专属的 AI 教练。所有阅读数据与知识卡片以纯文本形式存储在本地 Obsidian Vault 中，完全由你掌控。

> **核心理念**：把书读厚，再把书读薄——让 AI 陪你走完从阅读到内化的全过程。

## ✨ 核心功能

- **六种 AI 阅读教练**
  - **逻辑建构型**：苏格拉底式追问，帮你搭建严谨的概念体系。
  - **叙事审美型**：安静的文学伴侣，守护阅读沉浸感，只在需要时提供共鸣。
  - **行动指南型**：行为教练，将书中的方法转化为你的实际行动。
  - **工具查阅型**：高精度知识检索机，最快最准确地提供原文依据。
  - **批判思辨型**：忠实的反方辩友，在思想对弈中砥砺你的观点。
  - **技能建构型**：刻意练习教练，用问题驱动和错题本帮你真正掌握技能。

- **书架与进度管理**
  - 自动记录每本书的阅读进度、模式和上下文，随时无缝续读。
  - 一目了然的书架视图，管理在读书单、已读书单和藏书。

- **知识卡片自动生成**
  - 所有笔记、错题、章末总结均自动生成为标准化的知识卡片。
  - 卡片严格遵循 YAML 元数据 + 双链格式，完美融入 Obsidian 知识网络。
  - 支持三类笔记：主动记录、错题回顾、章末自动提取。

- **智能复习系统**
  - 基于间隔重复原理的错题复习，自动从你的知识库中提取错题进行测试。
  - 新知识教学前，自动检索你已掌握的相关概念，进行类比差异化教学。

  - 所有数据（书籍状态、笔记、知识卡片）均存储为本地纯文本文件。
  - 根目录同时作为 Obsidian Vault，直接兼容 Obsidian 原生双链和插件生态。

## 🚀 快速开始

### 1. 配置 WorkBuddy 与 Skill

1.  下载并安装 [WorkBuddy](https://workbuddy.ai) 客户端，登录你的账号。
2.  在 WorkBuddy 中导入本项目的 `skill.md` 文件（通常在 Skill 市场或设置中通过“导入”功能添加）。
3.  启动 Skill，它会以如下问候语开始：
    > "你好，我是你的 AI 阅读调度中心…请告诉我你的本地根目录和 Obsidian 知识库路径。"

### 2. 设置本地文件夹

1.  在你的电脑上创建一个专用文件夹，例如 `D:\AI阅读体系`（也可用 Skill 首次启动时推荐的默认路径）。
2.  将你希望 AI 辅助阅读的电子书（epub/pdf）放入该文件夹下的 `_inbox/` 子文件夹中。
3.  告诉 Skill 你的根目录路径（Skill 会在首次对话中询问）。Skill 会自动创建必要的子文件夹。

### 3. 配置 Obsidian Vault

1.  打开 Obsidian，点击“打开文件夹作为 Vault”，选择你刚创建的根目录（如 `D:\AI阅读体系`）。
2.  这样，AI 生成的所有知识卡片都会直接出现在你的 Obsidian 库中，可无缝使用双链、图谱等功能。

### 4. 开始你的第一本书

直接在 WorkBuddy 对话框中说：

> “开始读《思考，快与慢》”

Skill 会自动从 `_inbox/` 中找到书籍文件，完成入库，并根据书名智能推荐最合适的阅读模式，你只需确认即可。

## 📖 使用指南

### 📚 书籍入库

-   每次获得新书，只需将电子书文件放入 `_inbox/` 文件夹。
-   然后对 Skill 说：“开始读《书名》”。
-   Skill 会自动解析书名、创建专属文件夹、移动文件、更新书架。

### 🧠 选择阅读模式

当你说“开始读《书名》”时，Skill 会根据书名和简介自动推荐一个模式。你也可以手动指定：

> “用批判思辨型打开《理想国》”

可选模式：
-   `logic_building` - 逻辑建构型
-   `narrative_aesthetic` - 叙事审美型
-   `action_guide` - 行动指南型
-   `tool_reference` - 工具查阅型
-   `critical_thinking` - 批判思辨型
-   `skill_building` - 技能建构型

### 📝 记笔记

在阅读过程中，随时可以说：

> “记笔记：系统1是自动的、快速的、不费力的思维模式。”

Skill 会自动生成一张标准化的知识卡片，存入 Obsidian。

如果犯错，说：

> “加入错题本：我误把 apply 和 map 用混了。”

### 🧩 章节结束

每读完一章，说：

> “这章读完了。”

Skill 会自动扫描对话，提取你可能已掌握但未记录的知识点，列出待确认列表，你确认后一键生成 `learned` 卡片。

### 🔁 继续阅读

下次想继续时，只需说：

> “继续读《思考，快与慢》”

Skill 会从上次中断的地方无缝衔接。

### 🔄 复习

随时启动复习：

> “复习错题”

Skill 会从 Obsidian 知识库中提取所有 `type: mistake` 的卡片，按间隔重复算法出题测试。

### 📚 查看书架

> “我的书架”

会列出所有书籍及其状态、进度。

## ☁️ 多设备同步（可选）

由于所有数据都是本地文件，你可以使用任意文件同步工具实现跨设备同步。推荐方案：

1.  **Syncthing**（免费，P2P，推荐）：在所有设备上安装，共享同一根目录，实现实时双向同步。
2.  **Git + Gitee/GitHub**：将根目录作为 Git 仓库，利用 `Obsidian Git` 插件自动提交和拉取，同时获得版本历史。
3.  **绿联私有云**：使用绿联云客户端的“同步与备份”功能，通过 UGREENlink 远程同步。
4.  **iCloud / OneDrive / Dropbox**：将根目录放入云盘同步文件夹即可。

配置好同步后，你在任一设备上的阅读进度和笔记都会自动同步到其他设备。
